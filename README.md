# 📱 Contact Book

A simple Contact Book application built using Python, Object-Oriented Programming (OOP), JSON, and Streamlit.

This project allows users to add, view, search, update, and delete contacts.

## 🚀 Features

- ➕ Add Contact
- 📋 Show All Contacts
- 🔍 Search Contact
- ✏️ Update Contact
- 🗑️ Delete Contact
- ✅ Input Validation
- 💾 JSON File Storage
- ⚠️ Exception Handling
- 🖥️ Streamlit Web Interface

## 🛠️ Technologies Used

- Python
- OOP (Object-Oriented Programming)
- JSON
- Streamlit
- Git & GitHub
